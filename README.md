# learning-express
An introduction to APIs using Express

### pnpm commands
- `typecheck` - check for typescript errors
- `dev` - typecheck and run the application in developer mode (RUN `db:start` FIRST)
- `db:start` - start the postgres docker image for developer mode
- `db:stop` - stops the postgres docker image
- `db:reset` - wipes the postgres docker image and restarts it
